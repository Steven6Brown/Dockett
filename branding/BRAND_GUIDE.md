# Dockett — Brand Guide

**Working tagline (proposed):** Every receipt, right when you need it.

## The mark
A paper receipt with a zig-zag torn edge and an amber check badge: kept, verified, handled.

## Files
| File | Use |
|---|---|
| `dockett-app-icon.svg` / `.png` | App Store / home screen icon. 1024×1024, opaque, square (the system applies the rounded mask). |
| `dockett-mark-on-light.svg` / `.png` | Transparent mark for light backgrounds. |
| `dockett-mark-on-dark.svg` / `.png` | Transparent mark for dark backgrounds. |
| `dockett-wordmark-on-light.svg` / `.png` | Mark + name + tagline for light backgrounds. |
| `dockett-wordmark-on-dark.svg` / `.png` | Mark + name + tagline for dark backgrounds. |

## Palette
| Name | Hex | Use |
|---|---|---|
| Ink | `#14213D` | Backgrounds, text, icon field |
| Paper | `#F6F1E7` | Receipt, light surfaces |
| Amber | `#F2A33A` | Accent, deadlines, key actions |
| Slate | `#5B6478` | Secondary text |

## Type
Headings and numbers: SF Pro Rounded (bold). Body: SF Pro (system). The wordmark SVGs reference these fonts by name, so **convert the text to outlines in a vector editor before using a wordmark in print or on the web**, otherwise it will fall back to another font on machines without them.

## Voice
Calm, plain and reassuring. Short sentences. Lead with the deadline or the answer, never with the feature.

## Name check
On 2026-10-14 a search of the US App Store found no app titled exactly "Dockett". This is not a trademark search and not a guarantee the name will be accepted: check App Store Connect name availability and run a USPTO search before committing. Alternates considered: Stubbed, Docket (taken in a close variant).

## Icon rules
- Keep the mark inside the central ~80% of the icon canvas.
- No text on the icon.
- Check the icon at 60×60 pt and in dark, tinted and clear iOS appearances before submission.
